# MySlot · 只给熟人看的约见日历

朋友打开网页、输入分享码，就能看到你哪天能约、能约什么；挑好后生成一句话发给你，**最后由你确认**。网页上只有加密后的数据，没有码的人什么都看不到。

## 它怎么判断

程序每小时读取一次你的 iCloud 日历（也支持 Google、飞书），对每个人分别算出一份日历，再用那个人的分享码加密。

**日历格子只有符号：**

| 符号 | 意思 |
| --- | --- |
| ♡ | 有能直接选时间的活动 |
| 💬 | 可以商量（比如「问问我」、cos 这类只约日期的活动） |
| ✦ 名字 | 你公开给 Ta 的事，比如 ijoy、回老家 |
| — | 不对 Ta 开放，不说原因 |

图例和提示想加字，在设置页的「页面文字」里填；留空就只有符号。

**一天的判断顺序：**

1. **大安排**（聚会、cos、拍照、【休息】）、**已约**、**躺平** → 这天不接新的约。已经公开的漫展照常显示。
2. **活动的时段**：每个活动有自己的休息日 / 工作日时段和提前时间，扣掉普通活动占用的时间（休息日前后各留 1 小时）。
3. **同城**：吃饭这类要见面的活动，只对那天和你在同一个城市的人开放。日历写「回老家」，那天你就在老家，老家的朋友可以约你。
4. **漫展那天**：能看到漫展的人，可以在漫展时段约；漫展里的拍照等大安排只扣掉它自己的时间。
5. **每周上限**：一周的「已约」满 3 次后，这周不再接新的约。

## 日历里怎么标

关键词写在标题任何位置都可以，都能在设置页改：

| 标题里写 | 效果 |
| --- | --- |
| `聚会` `拍照` `cos` `【休息】` | 大安排：这天不接新的约 |
| `已约-星星`（写在开头） | 约好了：这天不接新的约，算一次 |
| `躺平` | 这天不接新的约 |
| `漫展-ijoy` | 公开项：能看到的人只看到「ijoy」 |
| `回老家`（全天） | 公开项，而且那天你在老家 |
| `预留-星星`（全天） | 这天只留给代号是「星星」的人 |
| `调休` / `补班`（全天） | 这天按休息日 / 工作日算 |
| 其他 | 普通活动，只扣掉它的时间，标题不公开 |

## 每个人看到什么

在 `settings.html` 的「分享码清单」里，每个人单独设置：

- **城市**：本地 / 老家……
- **能看到**：哪些公开项（漫展、回老家），或者某个具体名字（写了具体名字的码，会在那个活动结束后失效）
- **能约**：哪些活动
- **只看概括**：给长辈用，只看到你写的话，比如 上班 / 空闲 / 出去玩 / 在家
- 预留代号、称呼、有效期、备注

关系变了就点「修改」，码不变；想断开就「收回」。

## 主人视图

你自己有一个 24 位的主人码。打开后是**总览**：每天 × 每个人，一眼看到谁看到什么；也可以选「以某人的身份看」，看到的和 Ta 打开时一模一样。

## 设置和 Secrets

| 放哪 | 内容 |
| --- | --- |
| Secret `ICLOUD_USER` / `ICLOUD_APP_PASSWORD` / `MYSLOT_BUSY_CALENDARS` | iCloud 账号、App 专用密码、要读的日历名 |
| Secret `MYSLOT_CONFIG_JSON` | 设置页下载的 config.json 全部内容（排班、标记词、活动、概括、文字） |
| Secret `MYSLOT_SHARE_CODES` | 设置页「复制给 Secret」的内容 |
| Secret `MYSLOT_OWNER_CODE` | 主人码 |
| Variable `MYSLOT_LIVE` = `true` | 每小时自动同步 |

`settings.html` 只在你自己的电脑上打开，不会发布到网上。分享码清单原件 `myslot-codes.json` 建议放在 iCloud 云盘。

同步失败、配置写错时，程序不会乱开放：所有日子显示「—」，页面提示「日程暂时没有更新」，日志里用中文写出是哪一项设置有问题（只写名称，不写内容）。

## 本地运行

```sh
python3 -m unittest discover -s tests
python3 build.py --fixture --output dist        # 虚构数据；主人码 demo-owner-0000000
python3 -m http.server 8000 --directory dist
```
